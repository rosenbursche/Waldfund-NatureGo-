# Zitterpappel / Espe (Populus tremula) – Kennmerkmale fürs Icon
- Blatt fast kreisrund, so breit wie lang, kurz zugespitzt; Rand grob buchtig gezähnt (stumpfe, wellige Zähne).
- Stiel lang (etwa so lang wie die Spreite), seitlich abgeflacht – darum zittert das Laub; oft rötlich.
- Hellgrün, unterseits blasser; 3 kräftige Adern vom Grund.
- Hängende, graue, zottig behaarte Kätzchen im Vorfrühling (Fruchtersatz im Icon).
